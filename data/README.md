# Synthetic data

All records are fictional and generated by `doctree generate`. They are not ship or Seaspan data. Refer to manifest.json for the seed and counts.

The first word of each equipment name identifies its synthetic equipment class. required_docs.csv lists the required types for each class. row_id is a stable source record identifier, independent of the document ID and revision. injected_errors.csv records mutations and their expected consequences; multiple rows can describe the consequences of the same injection. File names are metadata; no PDFs exist.

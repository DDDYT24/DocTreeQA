# Workbook style

Use white backgrounds, black text and thin black table borders. Headers can use
light gray. Do not use dark blue banners or blue table themes. This is the
preferred default for future project styling too.

Keep pale red for errors and pale yellow for review warnings. These colours
identify problems; they are not decorative branding. Informational rows and
completeness bars use gray. Keep text readable when printed in grayscale.

Generated reports and presentation copies of reviewed workbooks use this style.
The exported VBA module creates matching tables when imported into Excel. An
older embedded module can still recreate its old formatting; see
[the replacement steps](update_review_module.md).

Demo images show selected ranges rendered from the uploaded reviewed workbook.
Presentation formatting and synthetic System display names are standardized.
The actual review decisions, audit values and totals are preserved. They are
not new screenshots of Windows macro execution.
